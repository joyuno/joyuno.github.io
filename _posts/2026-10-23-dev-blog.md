## GitHub Pages 빌드 13연속 실패 — Liquid syntax error 뒤에 숨은 프롬프트 유출

GitHub Pages 빌드가 **13연속 실패**했다. Pages 빌드 로그를 확인하니 `Liquid syntax error (line 217): 'raw' tag was never closed` 하나만 찍혀 있었다. 사이트가 13시간째 내려간 상태였다.

처음엔 최근에 올린 글에서 코드 블록을 닫는 걸 실수했나 싶었다. `grep`으로 `raw` 태그를 검색해 보니 `_posts/2026-10-16-dev-blog.md` 단 하나였다. 파일 225줄, 정확히 라인 217에서 에러가 났다.
